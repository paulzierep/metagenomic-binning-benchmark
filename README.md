## What this project is

We benchmark metagenomic genome binners with a repeatable harness — per-run
parameters, datasets, wall time / RAM, and bin quality scored with **CheckM2**
and **CheckM (v1)**. From now on we **focus only on
[COMEBin](https://github.com/paulzierep/COMEBin)** with the goal of making it
**the best binner**. Optimizations are developed on the
`comebin-optimizations-v11` branch (one commit per fix batch), validated
small → medium → large, and every evaluated run is recorded.

Got stitched-together by a long-form agent diary too:
[`docs/`](docs/) · full run history: [`docs/11-run-results.md`](docs/11-run-results.md).
